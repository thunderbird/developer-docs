# Android

This documentation is meant to help contributors get started, however the complete Thunderbird for Android documentation can be found here: [https://thunderbird.github.io/thunderbird-android/docs/latest/](https://thunderbird.github.io/thunderbird-android/docs/latest/)

This guide will walk the reader through each step of setting up a build environment, building Thunderbird for Android, and how to run the new build. The steps can be slightly different, depending on if you are running Windows, Linux, or MacOS so all 3 operating system platforms are covered.&#x20;
